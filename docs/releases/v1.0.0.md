# App Proxy v1.0.0 — Windows / macOS

## 下载与首次使用

| 平台 | 附件 | 使用方法 |
| --- | --- | --- |
| Windows | `AppProxy-1.0.0-Windows.zip` | 解压到固定目录，双击 `App Proxy.exe`，在「代理设置」填写本地 HTTP / Mixed 端口。 |
| macOS | `AppProxy-1.0.0-macOS-universal.zip` | 用 Finder 解压，把 `App Proxy.app` 放入「应用程序」，通过菜单栏图标配置并启动。包含 Apple Silicon 与 Intel 架构。 |
| 校验值 | `SHA256SUMS.txt` | 对照两个 ZIP 的 SHA-256。每个包另附 `BUILD-INFO.json`、中英文使用说明和 MIT 许可证。 |

Windows 助手要求 Windows 10 1903+ / Windows 11，以及系统自带的 .NET Framework 4.8+ 和 Windows PowerShell 5.1；macOS 助手要求 macOS 13+。两端都需要已安装且与系统兼容的官方 ChatGPT，以及已有的 HTTP / Mixed 代理。日常运行不需要 SDK、Node.js 或 Python。

首次应用配置前，请完全退出 ChatGPT，再从助手启动。在代理客户端的连接页面验证实际请求。系统代理和 TUN 可以保持关闭。

## 本版内容与边界

- Windows：原生托盘助手、保存本地代理端口、启动／显示、正常关闭后重启、进程身份与配置状态、轮转日志和可选登录自启动；程序为单个 EXE。
- macOS：原生 AppKit 菜单栏助手、应用与代理配置、正常重启、诊断与轮转日志、可选登录启动、自动启动和全局快捷键。
- 两端的自动启动选项默认关闭。退出助手后 ChatGPT 保持运行，普通重启流程不会强制结束目标应用。
- 代理入口不可用时保留原实例。Windows 中，若关闭窗口后仍有后台进程，请从 ChatGPT 自身菜单完全退出，再点击启动。
- 当前支持 ChatGPT。端口检测、启动参数和进程记录不等于全部流量已走代理；登录、聊天、上传、语音等功能需在代理客户端中分别验证。

Windows EXE 未签名；macOS 应用采用 ad-hoc 签名，没有 Apple Developer ID 签名或 Apple 公证。macOS 首次打开若被阻止，请确认来源后按「系统设置 → 隐私与安全性 → 仍要打开」操作，参见 [Apple 官方说明](https://support.apple.com/en-us/102445)。

构建流程在 Windows 上运行隔离测试，在 macOS 上运行模型与原生应用测试，并验证最终解压应用的签名与两种架构。包内构建信息记录确切源码提交；测试不控制真实 ChatGPT，真实代理路由需要使用者验证。

## Download and run

- **Windows:** download `AppProxy-1.0.0-Windows.zip`, extract it to a stable folder, and open `App Proxy.exe`. Configure your local HTTP/Mixed port (default `7890`). Requires Windows 10 1903+ / Windows 11 with its included .NET Framework 4.8+ and Windows PowerShell 5.1.
- **macOS:** download `AppProxy-1.0.0-macOS-universal.zip`, extract with Finder, move `App Proxy.app` to Applications, and use its menu bar icon. Requires macOS 13+ for the assistant; the app includes Apple Silicon and Intel slices.
- Both require a compatible, installed official ChatGPT app and an existing HTTP/Mixed proxy. No SDK, Node.js, or Python is needed for daily use. Interfaces currently use Chinese labels.

Quit ChatGPT completely before applying the proxy for the first time. Verify real requests in your proxy client's connections view; process detection does not establish routing for all native components. No system proxy or TUN configuration is changed. Automatic startup is off by default, and quitting the assistant leaves ChatGPT running.

The Windows executable is unsigned. The macOS bundle is ad-hoc signed without Developer ID signing or Apple notarization; if blocked, confirm the source and follow [Apple's first-open instructions](https://support.apple.com/en-us/102445).

`SHA256SUMS.txt` hashes both release ZIPs. Each package includes bilingual instructions, source/version metadata, and the MIT license. Isolated tests use fixture apps rather than real ChatGPT; actual app traffic requires manual verification.
